เพิ่ม Tutel📅 ลงหน้าจอโฮม

ครั้งแรกบนมือถือจะมีคำแนะนำขึ้นหนึ่งครั้งต่อเบราว์เซอร์ หากปิดไปแล้ว เปิดอีกครั้งได้จากปุ่ม “เพิ่มลงหน้าจอโฮม” ด้านล่าง sidebar

iPhone / iPad

  1. เปิด calendar.toomtoom.online ใน Safari
  2. แตะปุ่มแชร์ (รูปสี่เหลี่ยมที่มีลูกศรชี้ขึ้น) หากไม่พบ ให้เปิดเมนูเพิ่มเติมของ Safari
  3. เลื่อนหา “เพิ่มไปยังหน้าจอโฮม” (Add to Home Screen)
  4. หากมี “เปิดเป็นเว็บแอป” (Open as Web App) ให้เปิดไว้ ตั้งชื่อ แล้วแตะ “เพิ่ม”
  5. ออกไปหน้าจอโฮม แล้วแตะไอคอน Tutel📅 เพื่อเปิดแอป

ไม่พบตัวเลือกเพิ่ม? เลื่อนลงในเมนูแชร์แล้วแตะ “แก้ไขการทำงาน” (Edit Actions) เพื่อเพิ่มตัวเลือกนี้ ถ้าเปิดจาก Discord หรือแอปอื่น ให้เปิดลิงก์ใน Safari ก่อน

iOS ต้องเพิ่มผ่านเมนูของเบราว์เซอร์ เว็บไม่สามารถกดติดตั้งให้เองได้ การแจ้งเตือนต้องอนุญาตแยกในตั้งค่าการแจ้งเตือนของแอป และขึ้นอยู่กับอุปกรณ์/เวอร์ชันระบบ

Open the calendar in Safari → Share → Add to Home Screen → enable Open as Web App if shown → Add. Launch Tutel📅 from your Home Screen. If the action is missing, use Edit Actions in the share sheet.

Android

  1. เปิดเว็บใน Chrome หรือเบราว์เซอร์ที่รองรับการติดตั้งเว็บแอป
  2. ในหน้าคำแนะนำ กด “ติดตั้งแอป” แล้วกดยืนยันของเบราว์เซอร์
  3. หากไม่มีปุ่ม ให้เลือกเมนู ⋮ → “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก” ชื่อเมนูอาจต่างกัน

ปุ่มติดตั้งโดยตรงขึ้นเมื่อเบราว์เซอร์พร้อมให้ติดตั้ง ถ้าเปิดจากแชท ให้เปิดในเบราว์เซอร์ก่อน

Tap Install app and confirm the browser prompt. If unavailable, use the browser menu → Install app / Add to Home Screen. In-app browsers may require opening the link in Chrome first.

ทำไมคำแนะนำไม่ขึ้นอีก?

ระบบจำว่าเคยแสดงแล้วในเบราว์เซอร์นั้น เพื่อไม่รบกวนทุกครั้ง เปิดซ้ำได้จาก sidebar หากล้างข้อมูลเว็บหรือเปลี่ยนเบราว์เซอร์ อาจแสดงใหม่ เมื่อเปิดเป็นแอปอยู่แล้วจะซ่อนคำชวนติดตั้ง

The introduction appears once per browser storage. Reopen it from the sidebar. Clearing site data or switching browsers can show it again. Standalone app windows hide the installation entry.
