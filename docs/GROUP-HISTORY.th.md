# ประวัติกลุ่มและรายชื่อสมาชิก

## วิธีใช้

เลือกปฏิทินกลุ่ม แล้วเปิด **สมาชิกและสิทธิ์** หรือ **ประวัติกลุ่ม** จาก sidebar สมาชิกที่เข้าสู่ระบบและไม่ถูกระงับทุก role ดูได้เฉพาะกลุ่มที่ตนมีสิทธิ์ ผู้เข้าชมปฏิทินสาธารณะและสมาชิกของกลุ่มอื่นดูไม่ได้ ผู้ดูแลระบบหลักยังมีสิทธิ์จัดการตามเดิม

หน้าสมาชิกแสดงชื่อที่ใช้ในแอพ ผู้ให้บริการบัญชี role สถานะระงับ และวันเวลาที่เข้าร่วมกลุ่ม เวลาเข้าร่วมไม่ใช่เวลาสมัครบัญชี ถ้าออกแล้วเข้าร่วมใหม่จะได้เวลาใหม่ สมาชิกที่ย้ายจากระบบเดิมอาจแสดงวันที่ย้ายข้อมูล การดูรายชื่อไม่ได้ให้สิทธิ์แก้ role ลบสมาชิก หรือเข้า control panel เซิร์ฟเวอร์ ปุ่มจัดการยังอยู่เฉพาะเจ้าของและผู้จัดการ

หน้าประวัติแสดงว่าใครเข้าร่วม สร้าง แก้ไข ตรวจอนุมัติ ยกเลิก ลบหรือกู้คืนรายการ รวมถึงการจัดการสมาชิก คำเชิญ และการแจ้งเตือน Discord ที่ระบบบันทึกไว้ แสดงเวลาไทย Asia/Bangkok เรียงใหม่ก่อน ครั้งละ 50 รายการ มีปุ่มก่อนหน้า/ถัดไป บันทึกใหม่เก็บชื่อคนและชื่อกิจกรรม ณ ตอนทำรายการ จึงยังอ่านเข้าใจหลังเปลี่ยนชื่อหรือลบรายการ ชื่อเป็นชื่อที่แสดง ไม่ใช่การยืนยันตัวตนทางกฎหมาย

ไม่แสดงอีเมล ลิงก์/รหัสเชิญ token OAuth รายละเอียดกิจกรรม หรือ log เซิร์ฟเวอร์ สมาชิกเห็นชื่อกิจกรรมในประวัติของกลุ่ม รวมถึงกิจกรรมรออนุมัติ เพื่อให้ตรวจสอบการทำงานร่วมกันได้ ประวัติเก่าที่ไม่มีชื่อสำรองจะใช้ชื่อที่ยังเหลือในฐานข้อมูล หรือข้อความทั่วไป ระบบไม่สร้างประวัติย้อนหลังที่ไม่เคยบันทึกไว้ ดูวันเข้าร่วมเดิมได้จากหน้าสมาชิก ไม่มี API ให้สมาชิกลบประวัติ ไม่ใช่บันทึกความปลอดภัยที่ป้องกันการแก้ไขจากผู้ดูแลฐานข้อมูล และไม่ได้แสดงความแตกต่างทุกช่องก่อน/หลังแก้

## สำหรับผู้พัฒนา

ตารางใหม่ `audit_snapshots` และ index ถูกสร้างเมื่อเริ่มเซิร์ฟเวอร์ โดยไม่เปลี่ยนจำนวนคอลัมน์ของ `audit_log` เดิม `recordAudit` เก็บเฉพาะชื่อที่แสดงและชื่อรายการ ไม่เก็บข้อมูลคำเชิญทั้งหมด API อ่านตรวจ session และสิทธิ์กลุ่ม ส่วน API เขียนยังตรวจ role และ CSRF

`GET /api/members` เพิ่ม `joined_at` และเปิดให้อ่านสำหรับสมาชิก `GET /api/group/audit?page=1` คืน `{ items, page, hasMore }` รายการมี `id`, `action`, `created_at`, `actor_name`, `target_name` ไม่คืน token หรือรหัสเป้าหมายคำเชิญ รับเลขหน้าเต็ม 1-100000 ข้อมูลแต่ละกลุ่มแยกกัน ตัวแสดงประวัติใน `public/history.js` ใช้ข้อความ DOM ปกติ ไม่แทรก HTML จากชื่อผู้ใช้ และทิ้งผลโหลดเก่าหากสลับกลุ่มระหว่างรอ

การรับคำเชิญและสร้างปฏิทินใหม่บันทึก `membership.joined` การรับคำเชิญซ้ำขณะเป็นสมาชิกอยู่ไม่สร้างประวัติเข้าร่วมใหม่ สำรอง SQLite ก่อนอัปเกรด เริ่มบริการใหม่และโหลดหน้าเว็บใหม่เพื่อใช้โค้ดรุ่นนี้ ไม่ต้องกรอก secret หรือรัน SQL เอง เก็บประวัติเดิมไว้โดยไม่แต่งเติมย้อนหลัง ข้อมูลสำรองชื่ออยู่ภายใต้นโยบายเก็บฐานข้อมูลและ backup ของโปรเจค
