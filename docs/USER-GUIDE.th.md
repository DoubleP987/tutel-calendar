## สารบัญ

1. เข้าเว็บและบัญชี
2. เมนูและหมวดหมู่

6. ตั้งแจ้งเตือน
7. เพิ่มแอปลงหน้าจอโฮม

## 1. เข้าเว็บและบัญชี

เปิด https://calendar.toomtoom.online/ ผู้ชมที่ยังไม่เป็นสมาชิกเห็นวันทั่วไปของกลุ่มสาธารณะ เข้าระบบด้วย Google/Discord เพื่อสร้างหรือเข้าร่วมกลุ่ม กลุ่มส่วนตัวต้องมีสิทธิ์สมาชิก การรู้ลิงก์ไม่ใช่สิทธิ์ ผู้จัดการปฏิทินไม่ใช่ผู้ดูแลเซิร์ฟเวอร์

## 2. เมนูและหมวดหมู่

บนคอมมี sidebar ด้านซ้าย มือถือกด ☰ เพื่อเปิด ปิดด้วย × แตะนอกเมนู หรือเลือกหน้า หมวดหมู่ ธีมและบัญชีอยู่ด้านใน ชื่อกลุ่มด้านบนเปิดเมนูเปลี่ยนกลุ่ม เลือกเดือน/สัปดาห์/รายการ ใช้วันนี้ ลูกศร หรือปัดซ้าย–ขวาบนมือถือและค้นหาได้

ทุกกลุ่มรวมวันทั่วไปจากข้อมูลชุดกลาง ไม่สร้างสำเนาเมื่อสร้างกลุ่ม ค่าเริ่มต้นมีการศึกษา กิจกรรม/ชุมชน วันสำคัญและวันหยุด หมวดอื่นเลือกเพิ่มได้ เช่นวันหยุดราชการ ชดเชย ธนาคาร พุทธ วันพระ สถาบันพระมหากษัตริย์ ประเพณี ไทย สากล และมุสลิม การมีหมวดไม่ได้แปลว่ามีข้อมูลวันครบจากต้นทาง

สมาชิกบันทึกหมวดแสดงผลแยกกลุ่มในฐานข้อมูล ผู้ชมเก็บใน browser storage ธีมเก็บในเครื่องนั้น ตอนนี้แสดงกลุ่มที่เลือกพร้อมวันกลาง เลือกแสดงหลายกลุ่มที่มีสิทธิ์อ่านพร้อมกันได้จากการตั้งค่ามุมมอง โดยค่าเริ่มต้นเลือกเฉพาะกลุ่มปัจจุบัน

## 3. กลุ่มและสิทธิ์

เปิดชื่อกลุ่มเพื่อสร้าง เข้าร่วมด้วยคำเชิญ หรือสลับกลุ่ม กลุ่มใหม่เป็นส่วนตัว เจ้าของ/ผู้จัดการดูแลสมาชิก คำเชิญ และการอนุมัติ Editor แก้กิจกรรม native ที่เผยแพร่ได้ Member ส่งข้อเสนอและแก้ของตนที่ยังรอตรวจได้

## 4. เชิญสมาชิก

เลือกกลุ่ม เปิดจัดการกลุ่ม/เชิญสมาชิก แล้วเลือกวิธีเดียว:

- ลิงก์: สร้างแล้วคัดลอกส่งเอง
- อีเมล: ใส่ผู้รับ สิทธิ์ อายุ แล้วกดส่งได้เลย ไม่มี checkbox ซ้ำ หากส่งไม่สำเร็จระบบเก็บลิงก์ไว้และบอกข้อผิดพลาด
- รหัส: สร้างแล้วคัดลอกให้ผู้รับ

ผู้รับลิงก์เข้าสู่ระบบด้วย Google หรือ Discord บัญชีใดก็ได้แล้วกดรับคำเชิญ ลิงก์อีเมลใช้สำเร็จได้ครั้งเดียว ไม่ต้องมีอีเมลตรงกับปลายทาง คำเชิญไม่สร้างบัญชีปลอม CSV ที่ยืนยันแล้วสร้างคำเชิญและเข้าคิวส่งอีเมลทีละคน ไม่เปลี่ยนสิทธิ์เดิมและไม่ปลดระงับเอง ดูประวัติหรือเพิกถอนคำเชิญที่ยังไม่ใช้ได้

## 5. กิจกรรมและการอนุมัติ

กดวันที่หรือเพิ่มกิจกรรม ใส่ชื่อ รายละเอียด วันที่ ทั้งวันหรือเวลา หมวดและสี ผลลัพธ์ขึ้นกับ manual/trusted/all ของกลุ่ม ดูสถานะที่กิจกรรมของฉัน ผู้จัดการเปิดตรวจอนุมัติ การเปลี่ยนโหมดไม่อนุมัติรายการเก่าที่รอตรวจเอง

วันทั่วไปที่นำเข้าแก้ในเว็บสมาชิกไม่ได้ ต้องแก้ต้นทาง เมื่ออัปเดตทุกกลุ่มจะอ่านรายการกลางใหม่เหมือนกัน กิจกรรมที่ผู้ใช้เพิ่มยังเป็นของกลุ่มเดิม

## 6. ตั้งแจ้งเตือน

ตั้งค่าของฉันเลือกหมวดเตือน ระยะล่วงหน้า และเวลาทั้งวัน หมวดแสดงผลกับหมวดแจ้งเตือนคนละค่า ทั้งวันเตือนก่อนหนึ่งวันเที่ยงและวันจริงเวลาเริ่มต้น 07:00 ตาม Asia/Bangkok ผู้จัดการตั้งเตือนข้อเสนอรอตรวจแยกได้

การเตือนเข้าเครื่องต้องอนุญาต browser และรองรับอุปกรณ์ กล่องแจ้งเตือนยังใช้ได้เมื่อไม่รองรับ Push/badge การได้รับเมลจริงและ Push บนอุปกรณ์ยังไม่ยืนยันครบ ดู NOTIFICATIONS.md และ CURRENT-STATUS.md

## 7. เพิ่มแอปลงหน้าจอโฮม

เมื่อเข้าจาก iPhone/iPad หรือ Android ระบบจะแนะนำการติดตั้งหนึ่งครั้งต่อเบราว์เซอร์ หลังเข้าเว็บประมาณ 5 วินาที หากกำลังเปิดหน้าล็อกอินหรือหน้าต่างอื่นจะรอก่อน ปิดหรือกดไว้ทีหลังแล้วครั้งต่อไปจะไม่ขึ้นเอง เปิดอีกครั้งได้จาก **เพิ่มลงหน้าจอโฮม** ด้านล่าง sidebar ถ้าล้างข้อมูลเว็บหรือเปลี่ยนเบราว์เซอร์อาจขึ้นใหม่ หากเปิดเป็นแอปอยู่แล้วจะซ่อนคำชวนติดตั้ง

### iPhone / iPad

1. เปิด calendar.toomtoom.online ใน **Safari** หากเปิดจาก Discord ให้เปิดลิงก์ใน Safari ก่อน
2. แตะ **แชร์** รูปสี่เหลี่ยมมีลูกศรขึ้น อาจอยู่ในเมนูเพิ่มเติมของ Safari
3. เลื่อนแล้วเลือก **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen)
4. ถ้ามี **เปิดเป็นเว็บแอป** (Open as Web App) ให้เปิด ตั้งชื่อแล้วแตะ **เพิ่ม**
5. เปิดไอคอน Tutel📅 จากหน้าจอโฮม

หาตัวเลือกไม่พบ ให้เลื่อนเมนูแชร์ลงแล้วเลือก **แก้ไขการทำงาน** (Edit Actions) เว็บไม่สามารถเรียกหน้าติดตั้งแบบ Android บน iOS ได้ การอนุญาตแจ้งเตือนเป็นอีกขั้นตอนในตั้งค่าของแอป

### Android

กด **ติดตั้งแอป** แล้วกดยืนยันของเบราว์เซอร์ เมื่อเบราว์เซอร์รองรับและพร้อมให้ติดตั้ง ถ้าไม่ขึ้นให้เปิดใน Chrome แล้วเลือกเมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก** ชื่อเมนูขึ้นกับเบราว์เซอร์

[คู่มือบนเว็บ รองรับมือถือและเปลี่ยนธีมได้](https://calendar.toomtoom.online/install.html) ยังไม่ได้ทดสอบการติดตั้งจริงบนเครื่อง iOS/Android ในการอัปเดตนี้

อ้างอิง: [Apple](https://support.apple.com/en-by/guide/iphone/iphea86e5236/ios), [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Trigger_install_prompt)

## Public default and loading screen (10 October 2026)

The default public view has no selected group and shows “ยังไม่มีปฏิทิน”.
`GET /api/public/events` reads only the shared, published dataset, without group-local activities or group labels. It does not depend on CS SKRU membership/visibility. Signed-in users can still resume their selected calendar; explicit group links retain their group context and existing access checks.

`public/boot.js` displays an animated turtle splash while the initial session, group, catalog and event data load. It ends immediately on `tutel:ready`, with no artificial minimum delay. A slow request exposes retry after 15 seconds; load failure exposes an error and retry. `prefers-reduced-motion` disables animations. Installation onboarding waits until the loading overlay closes. Native operating-system splash screens remain controlled by the browser/OS; this animation runs inside the web app.

## ลบปฏิทินและกู้คืน

เฉพาะเจ้าของปฏิทิน: เปิดเมนูกลุ่ม → จัดการกลุ่ม → ลบปฏิทินนี้ แล้วพิมพ์ชื่อปฏิทินให้ตรงเพื่อยืนยัน ผู้จัดการ ผู้แก้ไข และผู้ดูแลเซิร์ฟเวอร์ไม่ได้สิทธิ์ลบจากบทบาทเหล่านั้น

กลุ่มจะอยู่ในถังขยะ 30 วัน สมาชิกเข้าไม่ได้ ระบบแจ้งเตือนของกลุ่มหยุด และคำเชิญเดิมถูกยกเลิก เจ้าของกู้คืนได้จากเมนูกลุ่ม → ถังขยะปฏิทิน → กู้คืนปฏิทิน กิจกรรม สมาชิก และการตั้งค่าจะกลับมา แต่ต้องสร้างคำเชิญใหม่ หากกลุ่มถูกระงับก่อนลบ การกู้คืนจะยังคงสถานะระงับเดิมไว้

เมื่อครบกำหนด ระบบลบกิจกรรมเฉพาะกลุ่ม สมาชิก คำเชิญ การเชื่อม Discord และประวัติแจ้งเตือนของกลุ่มออกจากฐานข้อมูลที่ใช้งานจริง วันทั่วไปที่ใช้ร่วมกันและบัญชีผู้ใช้ยังอยู่ การลบนี้ไม่ได้ล้างไฟล์สำรองหรือประวัติการตรวจสอบซึ่งมีนโยบายเก็บรักษาแยกกัน ข้อความที่ส่งไปแล้วหรือการส่งที่เริ่มทำงานแล้วเรียกคืนไม่ได้ ส่วนระบบแจ้งเตือนของบอทเดิมแยกจากเว็บนี้ การลบผ่านเว็บยังไม่หยุดการแจ้งเตือนของบอทเดิมจนกว่าจะเปลี่ยนไปใช้ worker ของระบบกลุ่ม

รายละเอียดสำหรับผู้พัฒนา: [Group deletion internals](GROUP-DELETION.md)

# คู่มือระบบกลุ่มและกิจกรรม

## เมนูไม่รก

หน้าปฏิทินยังเป็นหน้าหลัก กดชื่อกลุ่มเพื่อค้นหา เปลี่ยนกลุ่ม สร้าง/เข้าร่วม เลือกดูหลายกลุ่ม เปิดถังขยะ หรือออกจากกลุ่ม การจัดการกลุ่มรวมคำเชิญ กิจกรรมทั้งหมด ช่องแจ้งเตือน Discord ส่งออก และประวัติ ส่วนบัญชีของฉันรวมบัญชีที่เชื่อม คำขอโอนเจ้าของ และอุปกรณ์ที่เข้าสู่ระบบ การจัดการกิจกรรมรองอยู่ใน “จัดการและประวัติ” ช่องฉบับร่างและกิจกรรมซ้ำจะพับไว้ก่อน

## ออกจากกลุ่มและโอนเจ้าของ

สมาชิกออกเองได้ กิจกรรมที่เคยสร้างยังอยู่และไม่รับแจ้งเตือนกลุ่มอีก เจ้าของต้องโอนให้สมาชิกที่ยอมรับก่อน หรือย้ายปฏิทินเข้าถังขยะ ผู้จัดการนำสมาชิกและผู้แก้ไขออกได้ แต่เอาเจ้าของหรือผู้จัดการอีกคนออกไม่ได้ หากต้องห้ามกลับเข้ากลุ่มให้ใช้ระงับ การนำออกเพียงอย่างเดียวไม่ได้ห้ามรับคำเชิญใหม่

คำขอโอนเจ้าของใช้ได้ 7 วัน เจ้าของเดิมยังมีสิทธิ์จนผู้รับยอมรับ ผู้รับต้องยังเป็นสมาชิกที่ไม่ถูกระงับ หลังยอมรับเจ้าของเดิมจะเป็นผู้จัดการ ผู้ส่งยกเลิกได้ ผู้รับปฏิเสธได้ และการลบกลุ่มจะยกเลิกคำขอที่ค้าง การรับบทบาทไม่ได้เพิ่มสิทธิ์เข้าถึง control panel เซิร์ฟเวอร์

ผู้ที่ออกหรือถูกนำออกจะไม่ถูกคำเชิญอีเมลเดิมดึงกลับเข้ากลุ่มอัตโนมัติเมื่อ login แต่กดรับคำเชิญที่ยังใช้ได้เองเพื่อกลับเข้าได้ สิทธิ์สมาชิกเดิมไม่ถูกเปลี่ยนด้วยคำเชิญ การนำเข้า CSV จะแสดงจำนวนและข้ามอีเมลที่ยืนยันแล้วและเป็นสมาชิกอยู่ ต้องแก้อีเมลผิดและรายการซ้ำก่อนส่ง สถานะผู้ให้บริการรับอีเมลไม่ยืนยันว่าถึงกล่องขาเข้า

## ดูหลายกลุ่ม

เริ่มต้นเห็นเฉพาะกลุ่มที่กำลังเลือก เมนู “ปฏิทินที่แสดงร่วมกัน” ให้ติ๊กกลุ่มอื่นและจำไว้ในบัญชี กิจกรรมใหม่ยังเพิ่มลงกลุ่มปัจจุบัน ระบบตรวจสิทธิ์ทุกกลุ่มที่เลือกและตัดกลุ่มที่ออกหรือถูกระงับออก วันทั่วไปแสดงครั้งเดียว ไม่คัดลอกลงแต่ละกลุ่ม รายละเอียด รายการรายวัน และ tooltip ระบุชื่อกลุ่ม หน้าเว็บทั่วไปของผู้ไม่ login มีเฉพาะวันทั่วไป ส่วนลิงก์กลุ่มสาธารณะดูรายการที่เผยแพร่ได้โดยไม่ login กลุ่มส่วนตัวยังต้องมีสิทธิ์

## ฉบับร่างและกิจกรรมซ้ำ

เลือกบันทึกเป็นฉบับร่างเพื่อเก็บงานก่อน ยังไม่เผยแพร่หรือแจ้งผู้ตรวจ เมื่อต้องการส่งให้กดส่งฉบับร่าง ระบบใช้กฎอนุมัติของกลุ่ม การไม่อนุมัติต้องระบุเหตุผล ผู้ที่ไม่ได้สิทธิ์เผยแพร่โดยตรงจะต้องผ่านกฎอนุมัติอีกครั้งเมื่อแก้ไข

กิจกรรมที่เพิ่มในกลุ่มยกเลิกได้โดยยังเก็บประวัติ หรือย้ายเข้าถังขยะและกู้คืนภายใน 30 วัน การกู้คืนคืนสถานะเดิม ไม่บังคับเผยแพร่รายการที่รออนุมัติหรือเคยยกเลิก กิจกรรมที่นำเข้าหรือวันกลางต้องแก้ที่ต้นทาง

ตั้งซ้ำทุกวัน สัปดาห์ หรือเดือนได้ถึงหนึ่งปี ระบบเก็บกิจกรรมหลักหนึ่งรายการและคำนวณวันที่ตอนอ่าน ไม่สร้างสำเนาจำนวนมาก วันที่ 31 จะข้ามเดือนที่ไม่มีวันที่ 31 ปุ่มแก้หลักแก้ทั้งชุด เมนูรองของแต่ละครั้งให้ผู้ที่มีสิทธิ์เผยแพร่แก้เฉพาะครั้งหรือยกเลิกครั้งนั้นได้ ถ้าต้องผ่านการอนุมัติให้แก้ทั้งชุดเพื่อส่งตรวจ การแก้ทั้งชุดไม่ล้างข้อยกเว้นเดิมอัตโนมัติ

ประวัติบอกผู้ทำ เวลา และประเภทการทำงาน ไม่ได้เก็บภาพเนื้อหาก่อน/หลังทุกฉบับ การส่งออกเป็น JSON มีเนื้อหากิจกรรมเฉพาะกลุ่มและกฎซ้ำ ไม่มี secret อีเมลสมาชิก หรือข้อมูล session ไฟล์ส่งออกไม่ใช่ backup เต็ม: ไม่รวมข้อยกเว้น สมาชิก และประวัติ ต้องใช้ไฟล์สำรอง SQLite สำหรับกู้ระบบทั้งหมด

## แจ้งเตือนและบัญชี

ตั้งแจ้งเตือนกิจกรรมใหม่ ผลตรวจ ก่อนเริ่ม และการเปลี่ยน/ยกเลิกแยกตามกลุ่มได้ เปิดสรุปวันนี้เพื่อรวมกิจกรรมที่ตรงหมวดเป็นการแจ้งครั้งเดียวตามเวลาเตือนทั้งวัน ช่วงงดรบกวนใช้เวลาไทย งดส่งเข้าอุปกรณ์แต่เก็บในเว็บ ไม่ส่งย้อนหลังเมื่อพ้นช่วง ไม่เปลี่ยนเวลาแจ้งในห้อง Discord และต้องตั้งเวลาเริ่ม/สิ้นสุดต่างกัน ข้อความที่ส่งหรือเริ่มส่งแล้วเรียกคืนไม่ได้ งาน Discord ที่ยังรอและมีข้อมูลกิจกรรมเก่าจะถูกยกเลิก ไม่ส่งสรุปรายวันซ้ำอัตโนมัติหลังแก้กิจกรรม

หน้าอุปกรณ์แสดงชนิดโดยประมาณและวันหมดอายุ session เลือกออกจากเครื่องอื่นหรือทั้งหมดที่ไม่ใช่เครื่องปัจจุบันได้ บัญชีที่เชื่อมต้องเหลืออย่างน้อยหนึ่งบัญชีจึงถอดอีกบัญชีได้ และการถอดจะออกจาก session อื่น การออกจาก session ไม่ได้ยกเลิก Push subscription แยกของอุปกรณ์ ให้ปิดแจ้งเตือนอุปกรณ์ผ่านการตั้งค่าหากต้องการด้วย

## ส่วนที่ต้องแยกให้เข้าใจ

โค้ดปฏิทินจัดการข้อมูล กลุ่ม และงานแจ้งเตือน ส่วน TutelBot รับงานเพื่อส่ง Discord การเปิดระบบกลุ่มของบอทต้องย้ายช่องเดิมและตั้ง CALENDAR_GROUPS_ENABLED พร้อมกันทั้ง homeserver/Oracle จึงยังคงระบบเดิมไว้ก่อน แอป Tutel Calendar ใน Discord Developer ใช้ OAuth ไม่ใช่บอทอีกตัว เมื่อเปิดระบบแล้วใช้ /calendar connect ในช่องเป้าหมาย เปิดลิงก์ด้วย Discord คนเดียวกับผู้สั่ง เลือกกลุ่มและยืนยัน จากนั้นตั้งเวลา หมวด และทดสอบในช่องแจ้งเตือน Discord

เว็บยังรันบน homeserver บอทสำรอง Oracle ไม่ได้ทำให้เว็บสลับเครื่องตาม ส่วนการโอนฉุกเฉินผ่าน control panel หลักเป็นสิทธิ์ผู้ดูแลแพลตฟอร์มแยกจากขั้นตอนเจ้าของทั่วไป มีประวัติตรวจสอบ

รายละเอียด API ตารางฐานข้อมูล โครงสร้างไฟล์ และข้อจำกัด: [WORKFLOWS.md](WORKFLOWS.md) งานปฏิทินนี้ตรวจโค้ดและจัดรูปแบบแล้ว ไม่ได้ทดสอบลบ/ออก/โอนกับกลุ่มจริงหรือส่งอีเมลเป็นชุด การเริ่มบริการสำเร็จไม่ได้เท่ากับทดสอบครบทุกอุปกรณ์หรือ Push ส่วนบอทเพลงทดสอบ regression ที่เกี่ยวข้องผ่าน 19 กรณีแล้ว

## Invitation lifetime — 12 October 2026

New invitations default to no expiration (`days: 0` in the API, `expires_at: 0` in storage). The UI offers no expiry, 1, 7, 14 or 30 days; the API also accepts integer durations 1–30. This applies to link, email, code and newly created CSV invitations. Links and email invitations remain single-use. Codes retain their configured use limit. Revocation, membership restrictions and suspended/trashed-group checks still apply.

A one-time migration upgrades unused, unrevoked existing seven-day invitations to no expiration, including those whose seven days already elapsed. It preserves the invitation ID, token hash, role and email delivery state: previously sent links continue to work and no email is resent. Consumed/revoked invitations are not revived. Explicit finite invitations created after migration keep their chosen duration. Sessions, OAuth states and ownership transfer deadlines are unchanged.

Previously delivered emails may still say seven days: the server-side invitation now has no deadline; email contents cannot be edited retrospectively. Cancel an invitation from the group's invitation list whenever needed. Migration recovery requires the pre-change private SQLite snapshot (restore specific expiry values, not the whole live database).

คำเชิญใหม่ตั้งต้นไม่มีวันหมดอายุ เลือกจำนวนวันได้ในตัวเลือกเพิ่มเติม คำเชิญเดิม 7 วันที่ยังไม่ได้ใช้ครบและไม่ถูกยกเลิก ใช้ลิงก์เดิมได้โดยไม่ส่งเมลใหม่ ทั้งนี้ลิงก์/อีเมลยังใช้ได้ครั้งเดียว ข้อความวันที่ในอีเมลเก่าอาจยังเป็น 7 วัน แต่ระบบตรวจอายุจากฐานข้อมูลที่ปรับแล้ว
