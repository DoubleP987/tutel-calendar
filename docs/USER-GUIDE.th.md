# คู่มือผู้ใช้ Tutel Calendar

1. เข้าเว็บและบัญชี

3. กลุ่มและสิทธิ์
4. เชิญสมาชิก
5. กิจกรรมและการอนุมัติ
6. ตั้งแจ้งเตือน

## 1. เข้าเว็บและบัญชี

เปิด https://calendar.toomtoom.online/ ผู้ชมที่ยังไม่เป็นสมาชิกเห็นวันทั่วไปของกลุ่มสาธารณะ เข้าระบบด้วย Google/Discord เพื่อสร้างหรือเข้าร่วมกลุ่ม กลุ่มส่วนตัวต้องมีสิทธิ์สมาชิก การรู้ลิงก์ไม่ใช่สิทธิ์ ผู้จัดการปฏิทินไม่ใช่ผู้ดูแลเซิร์ฟเวอร์

## 2. เมนูและหมวดหมู่

บนคอมมี sidebar ด้านซ้าย มือถือกด ☰ เพื่อเปิด ปิดด้วย × แตะนอกเมนู หรือเลือกหน้า หมวดหมู่ ธีมและบัญชีอยู่ด้านใน ชื่อกลุ่มด้านบนเปิดเมนูเปลี่ยนกลุ่ม เลือกเดือน/สัปดาห์/รายการ ใช้วันนี้ ลูกศร หรือปัดซ้าย–ขวาบนมือถือและค้นหาได้

ทุกกลุ่มรวมวันทั่วไปจากข้อมูลชุดกลาง ไม่สร้างสำเนาเมื่อสร้างกลุ่ม ค่าเริ่มต้นมีการศึกษา กิจกรรม/ชุมชน วันสำคัญและวันหยุด หมวดอื่นเลือกเพิ่มได้ เช่นวันหยุดราชการ ชดเชย ธนาคาร พุทธ วันพระ สถาบันพระมหากษัตริย์ ประเพณี ไทย สากล และมุสลิม การมีหมวดไม่ได้แปลว่ามีข้อมูลวันครบจากต้นทาง

สมาชิกบันทึกหมวดแสดงผลแยกกลุ่มในฐานข้อมูล ผู้ชมเก็บใน browser storage ธีมเก็บในเครื่องนั้น ตอนนี้แสดงกลุ่มที่เลือกพร้อมวันกลาง การแสดงหลายกลุ่มพร้อมกันยังเป็นงานค้าง

## 3. กลุ่มและสิทธิ์

เปิดชื่อกลุ่มเพื่อสร้าง เข้าร่วมด้วยคำเชิญ หรือสลับกลุ่ม กลุ่มใหม่เป็นส่วนตัว เจ้าของ/ผู้จัดการดูแลสมาชิก คำเชิญ และการอนุมัติ Editor แก้กิจกรรม native ที่เผยแพร่ได้ Member ส่งข้อเสนอและแก้ของตนที่ยังรอตรวจได้

## 4. เชิญสมาชิก

เลือกกลุ่ม เปิดจัดการกลุ่ม/เชิญสมาชิก แล้วเลือกวิธีเดียว:

- ลิงก์: สร้างแล้วคัดลอกส่งเอง
- อีเมล: ใส่ผู้รับ สิทธิ์ อายุ แล้วกดส่งได้เลย ไม่มี checkbox ซ้ำ หากส่งไม่สำเร็จระบบเก็บลิงก์ไว้และบอกข้อผิดพลาด
- รหัส: สร้างแล้วคัดลอกให้ผู้รับ

อีเมลต้องตรงกับอีเมลที่ provider ยืนยันเมื่อเข้าสู่ระบบ คำเชิญไม่สร้างบัญชีปลอม CSV เพิ่มคำเชิญล่วงหน้าโดยไม่ส่งเมลจำนวนมาก ไม่เปลี่ยนสิทธิ์เดิมและไม่ปลดระงับเอง ดูประวัติหรือเพิกถอนคำเชิญที่ยังไม่ใช้ได้

## 5. กิจกรรมและการอนุมัติ

กดวันที่หรือเพิ่มกิจกรรม ใส่ชื่อ รายละเอียด วันที่ ทั้งวันหรือเวลา หมวดและสี ผลลัพธ์ขึ้นกับ manual/trusted/all ของกลุ่ม ดูสถานะที่กิจกรรมของฉัน ผู้จัดการเปิดตรวจอนุมัติ การเปลี่ยนโหมดไม่อนุมัติรายการเก่าที่รอตรวจเอง

วันทั่วไปที่นำเข้าแก้ในเว็บสมาชิกไม่ได้ ต้องแก้ต้นทาง เมื่ออัปเดตทุกกลุ่มจะอ่านรายการกลางใหม่เหมือนกัน กิจกรรมที่ผู้ใช้เพิ่มยังเป็นของกลุ่มเดิม

## 6. ตั้งแจ้งเตือน

ตั้งค่าของฉันเลือกหมวดเตือน ระยะล่วงหน้า และเวลาทั้งวัน หมวดแสดงผลกับหมวดแจ้งเตือนคนละค่า ทั้งวันเตือนก่อนหนึ่งวันเที่ยงและวันจริงเวลาเริ่มต้น 07:00 ตาม Asia/Bangkok ผู้จัดการตั้งเตือนข้อเสนอรอตรวจแยกได้

การเตือนเข้าเครื่องต้องอนุญาต browser และรองรับอุปกรณ์ กล่องแจ้งเตือนยังใช้ได้เมื่อไม่รองรับ Push/badge การได้รับเมลจริงและ Push บนอุปกรณ์ยังไม่ยืนยันครบ ดู NOTIFICATIONS.md และ CURRENT-STATUS.md
