# คู่มือระบบกลุ่มและกิจกรรม

[Current feature guide / คู่มือคุณสมบัติปัจจุบัน](CURRENT-FEATURES.md)

## เมนูไม่รก

หน้าปฏิทินยังเป็นหน้าหลัก กดชื่อกลุ่มเพื่อค้นหา เปลี่ยนกลุ่ม สร้าง/เข้าร่วม เลือกดูหลายกลุ่ม เปิดถังขยะ หรือออกจากกลุ่ม การจัดการกลุ่มรวมคำเชิญ กิจกรรมทั้งหมด ช่องแจ้งเตือน Discord ส่งออก และประวัติ ส่วนบัญชีของฉันรวมบัญชีที่เชื่อม คำขอโอนเจ้าของ และอุปกรณ์ที่เข้าสู่ระบบ การจัดการกิจกรรมรองอยู่ใน “จัดการและประวัติ” ช่องฉบับร่างและกิจกรรมซ้ำจะพับไว้ก่อน

## ออกจากกลุ่มและโอนเจ้าของ

สมาชิกออกเองได้ กิจกรรมที่เคยสร้างยังอยู่และไม่รับแจ้งเตือนกลุ่มอีก เจ้าของต้องโอนให้สมาชิกที่ยอมรับก่อน หรือย้ายปฏิทินเข้าถังขยะ ผู้จัดการนำสมาชิกและผู้แก้ไขออกได้ แต่เอาเจ้าของหรือผู้จัดการอีกคนออกไม่ได้ หากต้องห้ามกลับเข้ากลุ่มให้ใช้ระงับ การนำออกเพียงอย่างเดียวไม่ได้ห้ามรับคำเชิญใหม่

คำขอโอนเจ้าของใช้ได้ 7 วัน เจ้าของเดิมยังมีสิทธิ์จนผู้รับยอมรับ ผู้รับต้องยังเป็นสมาชิกที่ไม่ถูกระงับ หลังยอมรับเจ้าของเดิมจะเป็นผู้จัดการ ผู้ส่งยกเลิกได้ ผู้รับปฏิเสธได้ และการลบกลุ่มจะยกเลิกคำขอที่ค้าง การรับบทบาทไม่ได้เพิ่มสิทธิ์เข้าถึง control panel เซิร์ฟเวอร์

ผู้ที่ออกหรือถูกนำออกจะไม่ถูกคำเชิญอีเมลเดิมดึงกลับเข้ากลุ่มอัตโนมัติเมื่อ login แต่กดรับคำเชิญที่ยังใช้ได้เองเพื่อกลับเข้าได้ สิทธิ์สมาชิกเดิมไม่ถูกเปลี่ยนด้วยคำเชิญ การนำเข้า CSV จะแสดงจำนวนและข้ามอีเมลที่ยืนยันแล้วและเป็นสมาชิกอยู่ ต้องแก้อีเมลผิดและรายการซ้ำก่อนส่ง สถานะผู้ให้บริการรับอีเมลไม่ยืนยันว่าถึงกล่องขาเข้า

## ดูหลายกลุ่ม

เริ่มต้นเห็นเฉพาะกลุ่มที่กำลังเลือก เมนู “ปฏิทินที่แสดงร่วมกัน” ให้ติ๊กกลุ่มอื่นและจำไว้ในบัญชี กิจกรรมใหม่ยังเพิ่มลงกลุ่มปัจจุบัน ระบบตรวจสิทธิ์ทุกกลุ่มที่เลือกและตัดกลุ่มที่ออกหรือถูกระงับออก วันทั่วไปแสดงครั้งเดียว ไม่คัดลอกลงแต่ละกลุ่ม รายละเอียด รายการรายวัน และ tooltip ระบุชื่อกลุ่ม หน้าเว็บทั่วไปของผู้ไม่ login มีเฉพาะวันทั่วไป ส่วนลิงก์กลุ่มสาธารณะดูรายการที่เผยแพร่ได้โดยไม่ login กลุ่มส่วนตัวยังต้องมีสิทธิ์

## ฉบับร่างและกิจกรรมซ้ำ

เลือกบันทึกเป็นฉบับร่างเพื่อเก็บงานก่อน ยังไม่เผยแพร่หรือแจ้งผู้ตรวจ เมื่อต้องการส่งให้กดส่งฉบับร่าง ระบบใช้กฎอนุมัติของกลุ่ม การไม่อนุมัติต้องระบุเหตุผล ผู้ที่ไม่ได้สิทธิ์เผยแพร่โดยตรงจะต้องผ่านกฎอนุมัติอีกครั้งเมื่อแก้ไข

กิจกรรมที่เพิ่มในกลุ่มยกเลิกได้โดยยังเก็บประวัติ หรือย้ายเข้าถังขยะและกู้คืนภายใน 30 วัน การกู้คืนคืนสถานะเดิม ไม่บังคับเผยแพร่รายการที่รออนุมัติหรือเคยยกเลิก กิจกรรมที่นำเข้าหรือวันกลางต้องแก้ที่ต้นทาง

ตั้งซ้ำทุกวัน สัปดาห์ หรือเดือนได้ถึงหนึ่งปี ระบบเก็บกิจกรรมหลักหนึ่งรายการและคำนวณวันที่ตอนอ่าน ไม่สร้างสำเนาจำนวนมาก วันที่ 31 จะข้ามเดือนที่ไม่มีวันที่ 31 ปุ่มแก้หลักแก้ทั้งชุด เมนูรองของแต่ละครั้งให้ผู้ที่มีสิทธิ์เผยแพร่แก้เฉพาะครั้งหรือยกเลิกครั้งนั้นได้ ถ้าต้องผ่านการอนุมัติให้แก้ทั้งชุดเพื่อส่งตรวจ การแก้ทั้งชุดไม่ล้างข้อยกเว้นเดิมอัตโนมัติ

ประวัติบอกผู้ทำ เวลา และประเภทการทำงาน ไม่ได้เก็บภาพเนื้อหาก่อน/หลังทุกฉบับ การส่งออกเป็น JSON มีเนื้อหากิจกรรมเฉพาะกลุ่มและกฎซ้ำ ไม่มี secret อีเมลสมาชิก หรือข้อมูล session ไฟล์ส่งออกไม่ใช่ backup เต็ม: ไม่รวมข้อยกเว้น สมาชิก และประวัติ ต้องใช้ไฟล์สำรอง SQLite สำหรับกู้ระบบทั้งหมด

## แจ้งเตือนและบัญชี

ตั้งแจ้งเตือนกิจกรรมใหม่ ผลตรวจ ก่อนเริ่ม และการเปลี่ยน/ยกเลิกแยกตามกลุ่มได้ เปิดสรุปวันนี้เพื่อรวมกิจกรรมที่ตรงหมวดเป็นการแจ้งครั้งเดียวตามเวลาเตือนทั้งวัน ช่วงงดรบกวนใช้เวลาไทย งดส่งเข้าอุปกรณ์แต่เก็บในเว็บ ไม่ส่งย้อนหลังเมื่อพ้นช่วง ไม่เปลี่ยนเวลาแจ้งในห้อง Discord และต้องตั้งเวลาเริ่ม/สิ้นสุดต่างกัน ข้อความที่ส่งหรือเริ่มส่งแล้วเรียกคืนไม่ได้ งาน Discord ที่ยังรอและมีข้อมูลกิจกรรมเก่าจะถูกยกเลิก ไม่ส่งสรุปรายวันซ้ำอัตโนมัติหลังแก้กิจกรรม

หน้าอุปกรณ์แสดงชนิดโดยประมาณและวันหมดอายุ session เลือกออกจากเครื่องอื่นหรือทั้งหมดที่ไม่ใช่เครื่องปัจจุบันได้ บัญชีที่เชื่อมต้องเหลืออย่างน้อยหนึ่งบัญชีจึงถอดอีกบัญชีได้ และการถอดจะออกจาก session อื่น การออกจาก session ไม่ได้ยกเลิก Push subscription แยกของอุปกรณ์ ให้ปิดแจ้งเตือนอุปกรณ์ผ่านการตั้งค่าหากต้องการด้วย

## ส่วนที่ต้องแยกให้เข้าใจ

โค้ดปฏิทินจัดการข้อมูล กลุ่ม และงานแจ้งเตือน ส่วน TutelBot รับงานเพื่อส่ง Discord การเปิดระบบกลุ่มของบอทต้องย้ายช่องเดิมและตั้ง CALENDAR_GROUPS_ENABLED พร้อมกันทั้ง homeserver/Oracle จึงยังคงระบบเดิมไว้ก่อน แอป Tutel Calendar ใน Discord Developer ใช้ OAuth ไม่ใช่บอทอีกตัว เมื่อเปิดระบบแล้วใช้ /calendar connect ในช่องเป้าหมาย เปิดลิงก์ด้วย Discord คนเดียวกับผู้สั่ง เลือกกลุ่มและยืนยัน จากนั้นตั้งเวลา หมวด และทดสอบในช่องแจ้งเตือน Discord

เว็บยังรันบน homeserver บอทสำรอง Oracle ไม่ได้ทำให้เว็บสลับเครื่องตาม ส่วนการโอนฉุกเฉินผ่าน control panel หลักเป็นสิทธิ์ผู้ดูแลแพลตฟอร์มแยกจากขั้นตอนเจ้าของทั่วไป มีประวัติตรวจสอบ

รายละเอียด API ตารางฐานข้อมูล โครงสร้างไฟล์ และข้อจำกัด: [WORKFLOWS.md](WORKFLOWS.md) งานปฏิทินนี้ตรวจโค้ดและจัดรูปแบบแล้ว ไม่ได้ทดสอบลบ/ออก/โอนกับกลุ่มจริงหรือส่งอีเมลเป็นชุด การเริ่มบริการสำเร็จไม่ได้เท่ากับทดสอบครบทุกอุปกรณ์หรือ Push ส่วนบอทเพลงทดสอบ regression ที่เกี่ยวข้องผ่าน 19 กรณีแล้ว
